# parcel-typescript-tailwind-react

## About

This is the final output for [the blog post](https://umstek.github.io/blog/trying-out-tailwindcss-with-parcel/).

A Parcel + TypeScript + React + Tailwind CSS starter template, using pnpm.

## Commands

| Command             | What it does                            |
| ------------------- | --------------------------------------- |
| `pnpm install`      | Install dependencies                    |
| `pnpm dev`          | Dev server with HMR at `localhost:8080` |
| `pnpm build`        | Production build into `dist/`           |
| `pnpm lint`         | Lint with oxlint                        |
| `pnpm typecheck`    | Typecheck with `tsc --noEmit` (TS 7)    |
| `pnpm test`         | Run vitest tests once                   |
| `pnpm test:watch`   | Run vitest in watch mode                |
| `pnpm format`       | Format the repo with oxfmt              |
| `pnpm format:check` | Check formatting without writing        |
| `pnpm start`        | Clean, build and serve `dist/`          |
